Interpretable Deep Learning Models for Automated Medical Diagnosis: A Comprehensive Framework

Santos, M. A.; Silva, J.; Rodriguez, P. L.; Chen, W.
Nature Machine Intelligence, v. 8, n. 3, p. 245-267

Este trabalho apresenta um framework abrangente para o desenvolvimento de modelos de deep learning interpretáveis aplicados ao diagnóstico médico automatizado. A metodologia proposta combina técnicas de attention mechanisms com explainable AI (XAI) para fornecer diagnósticos precisos e interpretáveis. Os resultados demonstram uma melhoria de 12% na precisão diagnóstica em comparação com métodos tradicionais, mantendo alta interpretabilidade para profissionais médicos.

PDF DOI Código
